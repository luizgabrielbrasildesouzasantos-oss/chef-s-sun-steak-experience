# Chef's Sun Steak Experience

Quero que você crie um website COMPLETO, PROFISSIONAL, PREMIUM E MUITO VISUAL para o restaurante "Carne de Sol do Chef".

A imagem de referência anexada mostra o Instagram atual do restaurante. USE ESSA IMAGEM COMO REFERÊNCIA PRINCIPAL para entender a identidade visual, atmosfera, cores, estilo gastronômico, apresentação dos pratos e posicionamento da marca.

IMPORTANTE:

Não quero um site com aparência de template.

Não quero aparência de projeto gerado por IA.

Não quero excesso de cards, gradientes, sombras exageradas ou elementos genéricos.

Quero que o resultado pareça ter sido criado por uma agência especializada em restaurantes premium.

O site precisa transmitir:

- gastronomia brasileira

- carne de sol

- qualidade

- tradição

- sofisticação

- experiência gastronômica

- ambiente acolhedor

- restaurante moderno

- desejo de visitar o restaurante

- desejo de pedir comida

- confiança

==================================================

1. IDENTIDADE VISUAL

==================================================

Use como base a identidade visual observada na imagem de referência.

Paleta principal:

- preto quase absoluto

- preto carvão

- dourado sofisticado

- amarelo/dourado utilizado apenas como destaque

- branco/off-white para textos

- tons quentes de marrom/bege nas fotografias

O dourado deve ser usado com MUITO cuidado.

Não transforme o site em um site amarelo.

A maior parte da interface deve ser preta/escura, elegante e cinematográfica.

Tipografia:

Utilize uma combinação sofisticada de fonte serifada para títulos e uma fonte sans-serif moderna para textos e navegação.

Os títulos devem ter personalidade.

Evite fontes excessivamente futuristas.

A sensação deve lembrar:

"restaurante brasileiro premium + editorial gastronômico + arquitetura sofisticada".

4. HERO — PRIMEIRA IMPRESSÃO

DO CHEF"

- subtítulo aparece depois

- botões aparecem por último

Tudo deve ser suave.

Nada deve piscar.

==================================================

5. EFEITO DE SCROLL CINEMATOGRÁFICO

==================================================

Quero MUITO cuidado com as animações.

Use animações modernas semelhantes a websites premium de restaurantes.

Ao rolar:

- textos entram suavemente

- imagens fazem pequeno parallax

- elementos aparecem conforme entram na viewport

- títulos podem ter reveal vertical

- imagens podem aparecer com clip/reveal

- pequenos elementos podem deslocar alguns pixels

Não exagerar.

A animação deve parecer natural e sofisticada.

Use:

- IntersectionObserver

- CSS transforms

- opacity

- translateY

- scale

- parallax leve

Evite animações pesadas que deixem o site lento.

IMPORTANTE:

Todas as animações devem respeitar prefers-reduced-motion.
